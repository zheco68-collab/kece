## 一、 最新需求追加与细节规划

在已选定的「左侧粗指示条 + 纯粹导航项 + 68px 折叠悬浮气泡」基础上，追加以下两项**个人主页（Profile）**联动能力：

### 1. 侧边栏独立「个人主页」导航项
- **路由路径**：`/profile`
- **排布位置**：挂载于侧边栏导航区域，作为第 8 个核心功能入口：
  - `01 // 首页` (`/`)
  - `02 // 题库 ▾` (`/questions`，手风琴下挂：算法编程、数据库题、客观理论)
  - `03 // 题集` (`/problem-sets`)
  - `04 // 课练` (`/practice`)
  - `05 // 考试` (`/exams`)
  - `06 // 排名` (`/rankings`)
  - `07 // 公告栏` (`/announcements`)
  - `08 // 个人主页` (`/profile`) ⭐ **新增**
- **专属视觉与图标**：配属标准的 User 用户轮廓线性 SVG 图标；
- **响应式与状态联动**：
  - 访问 `/profile` 或选手详情页 `/profile/:id` 时，自动点亮左侧 `3px` 纯黑指示重音条；
  - 侧边栏收缩至 `68px` 紧凑态时，鼠标悬停 User 图标向右侧平滑滑出 Flyout 气泡：`08 // 个人主页 - 做题战绩与提交记录`。

### 2. 底部用户卡片：头像与名字可点击直达个人主页
- **热区与交互规范**：
  - 整个用户卡片（头像、用户名）采用 `<RouterLink to="/profile">` 封装，赋予明确的 `cursor: pointer`；
  - **头像 Hover 态**：外框由浅灰线 `border: 1px solid var(--line)` 平滑强化为 `#111111` 纯黑工程硬边；
  - **用户名 Hover 态**：字体颜色加深，并自动显示 `text-decoration: underline;` 下划线引导；
  - **辅助文字提示**：用户名字下方副标签展示 `UID: 27 · 点击进主页 ↗`，全局带 `title="点击进入个人主页"` 原生浮层；
  - **操作互不冲突**：用户卡片下方独立保留 `[后台管理 →]` 主按钮（仅管理员/教师可见）与 `[退出]` 按钮，各功能热区互不挤压。

## 三、 未登录状态优雅降级

- 当访客未登录（`userStore.isLoggedIn === false`）：
  - 侧边栏导航区的「个人主页」项：点击时通过路由守卫重定向至 `/login?redirect=/profile`；
  - 侧边栏底部：不展示个人信息与后台按钮，替换为高亮醒目的全宽直角 `[登录 / 注册]` 入口按钮。
